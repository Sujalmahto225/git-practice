# Git and GitHub Practical

## Objective

The objective of this practical is to learn and perform basic Git and GitHub operations using Linux.

## Operations Performed

The following Git operations were performed:

1. Initialized a local Git repository using `git init`.
2. Created a text file and added content to it.
3. Checked the repository status using `git status`.
4. Added the file to the staging area using `git add`.
5. Committed the changes using `git commit`.
6. Created a repository on GitHub.
7. Connected the local repository to GitHub using `git remote add`.
8. Pushed the local repository to GitHub using `git push`.
9. Modified the text file and committed the changes.
10. Pushed the updated changes to GitHub.
11. Cloned the GitHub repository into another local directory using `git clone`.
